# Week-by-week checklist

Use with [PLAN.md](PLAN.md) and [STATUS.md](STATUS.md).  
**Total program:** 16 weeks (**14 work** + **2 buffer**).

**How work works:** Each phase has a **[WORKSHEET.md](docs/phases/WORKSHEET-GUIDE.md)** (progress) and **`tasks/`** (context + inspiration). Tick when ready to discuss; link your notes. Example questions are lenses, not a test.

**Canonical DoD:** tasks ticked when ready to discuss (+ gate pack if any).  
Evidence can live in stubs, `evidence/`, or elsewhere — link from the worksheet.

**Week 1 start / program end:** see [meetings/SCHEDULE.md](meetings/SCHEDULE.md)

**Program priorities (2026 rebalance):**

- **Figma is primary** Weeks 8–11 (~70% Malte time); data/ops run in parallel, not at the expense of screens.
- **Week 7 = scope pivot only** — lock feature lists; no Figma frames yet.
- **Gate 4 (Week 12)** = MVP + V2 **build-ready** Figma; V3 = **roadmap/directional** frames (polish in buffer).
- **Finance spreads** Weeks 5 (hypotheses) → 12 (sheet skeleton) → 13 (Gate 5).
- **Risk rolls** from Week 1 ([RISK-REGISTER.md](docs/phases/10-risk/RISK-REGISTER.md)); Week 14 = synthesis + Gate 6.

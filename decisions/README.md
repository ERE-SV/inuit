# Decisions

Material choices are logged here. If it is not in [DECISION-LOG.md](DECISION-LOG.md), it is **not** locked.

## When to log

- Any **gate** outcome (required same day)
- Any weekly provisional call that later work will depend on
- Scope changes to MVP/V2/V3 after the scope checkpoint
- Reversal or superseding of a prior decision

## IDs

Use `D-001`, `D-002`, … in order. Never reuse IDs. To change a decision, add a new entry with `Supersedes: D-00X`.

## Template

Copy [templates/decision.md](templates/decision.md) into `D-XXX-short-slug.md` for long-form writeups when needed. Short decisions can live only in the log table.
